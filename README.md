# Vision Language Model for Multilingual Visual Question Answering

This repository contains code and resources related to a Vision Language Model (VLM) for answering visual questions in a multilingual context. The project explores the fine-tuning and evaluation of VLMs for the ImageCLEF 2025 challenge.

## Project Structure and Key Files

*   `1. Original Model Predicting Answer JSON.ipynb`: This notebook focuses on the initial setup and prediction using a base Qwen2-VL model. It involves installing `unsloth` and `transformers`, loading the `Rocktim/EXAMS-V` dataset, and likely generating initial answer predictions in JSON format.
*   `2. FineTuning Original Model With Output NEW.ipynb`: Iit is dedicated to fine-tuning the original VLM with new output data, which likely involves training processes and dataset preparation for improved performance.
*   `3. FineTuned Model Test.ipynb`: This notebook is used for testing the performance of the fine-tuned VLM. It involves loading the base model, applying PEFT (Parameter-Efficient Fine-Tuning) adapters from `vinayak_model.zip`, and evaluating the model on the `Rocktim/EXAMS-V` dataset.
*   `4. FineTuned Model Frontened Live.ipynb`: This notebook sets up a live frontend for the fine-tuned model, likely using `Streamlit` for the UI and `pyngrok` to expose it publicly. It also handles downloading and unzipping the `vinayak_model.zip` and loading the `Rocktim/EXAMS-V` dataset.
*   `5.Vinayak_ImageCLEF_2025_Submission_.ipynb`: This notebook  contains the final code for the ImageCLEF 2025 challenge submission. Similar to the test notebook, it loads the fine-tuned model with PEFT adapters and might include specific steps for generating submission-ready results.
*   `Answer_Analysis.ipynb`: This notebook is for analyzing the answers generated by the models, presumably to evaluate their quality and identify areas for improvement.
*   `Video File.mp4`: A video demonstrating the model's capabilities or a related visual asset.
*   `run_results.json`: Contains the results from various model runs.
